# GetCheapViews - Modern Website Redesign

A high-performance, modern, and aesthetic redesign for **GetCheapViews** (`https://getcheapviews.com/`), architected for high conversion and natural social proof acceleration across 12+ social platforms.

---

## ✨ Features & Architecture

- **Clean Typography**:
  - Primary Font: [Figtree](https://fonts.google.com/specimen/Figtree) (Headings, buttons, badges)
  - Secondary Font: [Inter](https://fonts.google.com/specimen/Inter) (Body text, descriptions)
- **Authentic Brand Identity**:
  - Anchored with the official GetCheapViews cyan-blue (`#14A2DD`).
  - Balanced multi-tone accent system (YouTube Red, Instagram Pink, Spotify Green, SoundCloud Orange, Snapchat Gold, Twitch Purple, etc.) to eliminate monotone saturation.
- **Modern UI Components**:
  - **Split-Grid Hero**: Live dispatch velocity monitor and real-time operational status.
  - **Spotlight Command Palette (`Ctrl+K`)**: Floating search modal with instant live autocomplete, trending tags, and direct 1-click ordering.
  - **Catalog Search & Filtering**: In-page search bar and platform filter tabs (10 initial featured services with "View All Services" expander).
  - **Asymmetric Bento Grid**: Algorithm-safe discovery, password-free guarantee, 30-day auto-refill, and instant cloud dispatch.
  - **Interactive Order Modal**: Real-time quantity selectors (1K, 5K, 10K), instant total calculation, link & email inputs.
  - **Real-Time Toast Notifications**: Simulated live order dispatch notifications in the corner.
  - **Automated Wholesale Partner Promotion**: Prominent callouts and banner for bulk reseller infrastructure on `getcheapview.net`.

---
